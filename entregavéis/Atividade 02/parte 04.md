**ScrollView:** Utilizado como container principal para permitir a rolagem da tela caso o conteúdo ultrapasse o tamanho visível.
> *   **View:** Container básico para organizar elementos (layout) e agrupar componentes.
> *   **Text:** Componente para exibição de texto na interface.
> *   **Image:** Utilizado para exibir a imagem (logo) carregada via URL.
> *   **TextInput:** Campo de entrada que permite ao usuário interagir e digitar informações.
> *   **TouchableOpacity:** Componente de toque utilizado como botão, que oferece feedback visual (opacidade) ao ser pressionado pelo usuário.
